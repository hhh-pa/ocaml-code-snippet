# ocaml-code-snippet

A curated collection of commonly used algorithms in OCaml, ported from the reference implementations in [cpp-code-snippets](https://github.com/m-hu/cpp-code-snippets).

Each snippet is implemented in standalone OCaml using standard library modules only, with optimal time and space complexity matching the C++ reference implementations.
